# راهنمای ویرایش موشن‌استوری «فریم‌باز»

این پوشه یک **موتور ساخت موشن‌گرافیک** است: متن، رنگ، ترتیب صحنه‌ها و گویندگی را می‌دهی،
ویدیوی عمودی ۹:۱۶ (۱۰۸۰×۱۹۲۰) با **گویندگی فارسی + زیرنویس انگلیسی** تحویل می‌گیری.

---

## ۱) خروجی‌ها (پوشه `out/`)

| فایل | توضیح |
|---|---|
| `framebaz_reel_full_music.mp4` | **ویدیوی اصلی** ~۴۹ ثانیه، ۹ صحنه، با گویندگی + موسیقی ملایم |
| `framebaz_reel_full_vonoly.mp4` | همان تصویر، فقط گویندگی (بدون موسیقی) — مناسب وقتی می‌خواهی در اینستاگرام یک آهنگ ترند روی آن بگذاری |
| `framebaz_reel_short_music.mp4` | نسخه کوتاه ~۳۱ ثانیه (مناسب تبلیغ/ریلز کوتاه) |
| `cover_frame.png` / `cover.png` | فریم آماده برای کاور ریلز + کاور طراحی‌شده |
| `storyboard.md` | استوری‌بورد: زمان‌بندی، متن فارسی، زیرنویس انگلیسی، متن گویندگی و توضیح حرکت هر صحنه |

## ۲) تغییر متن‌ها

* **زیرنویس انگلیسی و متن گویندگی**: فایل `brand.json` → بخش `scenes`
  (`caption_en` = زیرنویس، `vo` = متنی که گوینده می‌خواند).
* **تیتر بزرگ فارسی، برچسب کارت‌ها، اعداد آماری**: فایل `framebaz/brand.py` →
  `SCENES` (`fa_lines`, `cards`, `stats`).
* **نام پیج، آیدی و شعار**: `brand.json` → `handle` / `name_fa` / `tagline_en`.

## ۳) تغییر رنگ و هویت بصری

`brand.json` → `brand.colors`. رنگ‌های اصلی:
`magenta`، `yellow`، `lime`، `cyan`، `ink` (زمینه تیره)، `blue`.
هر صحنه رنگ پس‌زمینه خودش را دارد (`bg` در `brand.py`).

## ۴) تغییر گویندگی

فایل‌های `audio/vo_00.mp3` تا `audio/vo_07.mp3` به ترتیب همان صحنه‌های ۱ تا ۸ هستند:

| فایل | صحنه |
|---|---|
| `vo_00.mp3` | هوک (با ویدیو دیده شو) |
| `vo_01.mp3` | خدمات |
| `vo_02.mp3` | آموزش انیمیشنی / استاپ‌موشن |
| `vo_03.mp3` | مراحل کار |
| `vo_04.mp3` | نتیجه |
| `vo_05.mp3` | نمونه‌کارها |
| `vo_06.mp3` | معرفی سازنده (کاراکتر فریم‌باز) |
| `vo_07.mp3` | فریم‌باز |
| `vo_08.mp3` | دایرکت بده |

کیفیت خوب = ضبط در محیط ساکت با فاصله ~۰.۳ ثانیه سکوت در ابتدا و انتهای فایل.
طول ویدیو خودکار با طول گویندگی تنظیم می‌شود؛ لازم نیست چیزی را دستی تغییر دهی.

> اگر فایل گویندگی فایل را با ابزار دیگری ساختید، فقط همان نام `vo_XX.mp3` را جایگزین کنید
> (mp3 یا wav، هر دو کار می‌کند).

## ۴.۵) عوض کردن تصویر کاراکتر

تصویر کاراکتر (مرد با بره و کلاکت) در `assets/mascot_source.png` است. اگر تصویر جدیدی داری:

```bash
cd motion
export PYTHONPATH=~/.local/share/framebaz/pylibs:$(pwd)
python3 tools/make_mascot.py /مسیر/تصویر-جدید.png
```

اسکریپت پس‌زمینه کاغذی را حذف می‌کند و سه خروجی می‌سازد: کارت دست‌ساز (`mascot_card.png`)،
بج دایره‌ای چهره (`mascot_badge.png`) و نسخهٔ بدون پس‌زمینه (`mascot.png`).
کارت در صحنهٔ «معرفی سازنده» و بج در صحنهٔ پایانی استفاده می‌شوند.

## ۵) ساخت دوباره ویدیو (یک دستور)

```bash
cd motion
export PYTHONPATH=~/.local/share/framebaz/pylibs:$(pwd)
bash tools/make_all.sh
```

زمان تقریبی: ~۳ دقیقه برای نسخه اصلی + ~۲ دقیقه برای نسخه ۳۰ ثانیه‌ای.
اگر فقط متن‌ها را عوض کرده‌اید و گویندگی را نه، همین دستور کافی است.

## ۶) تنظیم زمان‌بندی

در `framebaz/brand.py` برای هر صحنه:

* `min_dur` = حداقل طول صحنه (ثانیه)
* `lead` = فاصله قبل از شروع گویندگی در آن صحنه
* `tail` = فاصله بعد از پایان گویندگی

## ۷) نکات انتشار در اینستاگرام

* ویدیو ۱۰۸۰×۱۹۲۰ و ۳۰ فریم است؛ هم برای **ریلز** هم **استوری** قابل استفاده است.
* نسخه `vonoly` را انتخاب کن اگر می‌خواهی آهنگ ترند اضافه کنی.
* کاور: `cover_frame.png` را به‌عنوان Cover ریلز انتخاب کن.
* متن‌ها داخل ناحیه امن (بدون تداخل با دکمه‌ها/کپشن اینستاگرام) چیده شده‌اند.

## ۸) صحنه جدید اضافه کنم؟

۱. یک بلوک جدید در `SCENES` فایل `framebaz/brand.py` بساز (`id`, `template`, `bg`, `fa_lines`, `caption_en`, `vo`).
۲. بلوک متناظر را در `brand.json` اضافه کن.
۳. اگر ظاهر جدیدی می‌خواهی، یک تابع `tpl_*` در `framebaz/templates.py` بنویس و در `TEMPLATES` ثبت کن.
۴. فایل گویندگی همان صحنه را با شماره بعدی (`vo_09.mp3`) اضافه کن و `make_all.sh` را اجرا کن.
